Déploiement avec Docker

Lancez RavaLink dans un conteneur avec Docker Compose ou une construction manuelle.

Image officielle RavaLink

Pour déployer une release, utilisez directement l’image publiée sur GitHub Container Registry. Elle est multi-architecture (Linux AMD64 et ARM64) et c’est la même image runtime que celle utilisée par l’egg officiel Pelican/Pterodactyl.

ghcr.io/ravalink-project/ravalink:latest
# ou une version précise
ghcr.io/ravalink-project/ravalink:v1.0.0-rc.2
Déploiement sur un panel : si vous utilisez Pelican ou Pterodactyl, suivez plutôt le guide dédié aux panels.

Docker Compose

Créez un dossier de déploiement avec les répertoires persistants :

mkdir -p ravalink/config ravalink/plugins ravalink/data
cd ravalink

Créez compose.yml :

services:
  ravalink:
    image: ghcr.io/ravalink-project/ravalink:latest
    container_name: ravalink
    restart: unless-stopped
    environment:
      STARTUP: "ravalink"
      RAVALINK_ADDRESS: "0.0.0.0"
      RAVALINK_PORT: "2333"
      RAVALINK_PASSWORD: "REMPLACER_PAR_UN_SECRET_LONG"
      RAVALINK_PLUGINS_DIRECTORY: "/home/container/plugins"
      RAVALINK_YOUTUBE_OAUTH_ENABLED: "false"
      RAVALINK_YOUTUBE_OAUTH_TOKEN_FILE: "/home/container/data/youtube-oauth.json"
    ports:
      - "127.0.0.1:2333:2333"
    volumes:
      - ./config:/home/container/config
      - ./plugins:/home/container/plugins
      - ./data:/home/container/data

Générez un secret aléatoire, remplacez la valeur d’exemple, puis démarrez :

openssl rand -hex 32
docker compose up -d
docker compose logs -f ravalink

L’image utilise un point d’entrée compatible panel et attend la variable STARTUP. En dehors de Pelican/Pterodactyl, définissez-la à ravalink. Le fichier de configuration facultatif est lu depuis /home/container/config/ravalink.toml.

Conserver les jetons OAuth YouTube

Le volume ./data:/home/container/data conserve le fichier de jetons entre les recréations du conteneur. Pour activer OAuth, passez RAVALINK_YOUTUBE_OAUTH_ENABLED à true, puis suivez le guide d’autorisation YouTube. Ne supprimez pas le dossier data lors d’une mise à jour.

Lancement avec docker run

docker run -d \
  --name ravalink \
  --restart unless-stopped \
  -e STARTUP=ravalink \
  -e RAVALINK_ADDRESS=0.0.0.0 \
  -e RAVALINK_PORT=2333 \
  -e RAVALINK_PASSWORD="$(openssl rand -hex 32)" \
  -p 127.0.0.1:2333:2333 \
  -v "$PWD/config:/home/container/config" \
  -v "$PWD/plugins:/home/container/plugins" \
  -v "$PWD/data:/home/container/data" \
  ghcr.io/ravalink-project/ravalink:latest

Mises à jour

Pour suivre les dernières releases, utilisez latest. Pour un déploiement reproductible, épinglez une version. Avec Compose, récupérez la nouvelle image puis recréez le conteneur :

docker compose pull
docker compose up -d

Le panel Pelican/Pterodactyl gère le téléchargement de l’image au redémarrage selon son fonctionnement Wings. Consultez le guide panel pour les détails.

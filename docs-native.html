Installation Linux native

Installez RavaLink directement sur Linux avec un binaire autonome et un service systemd.

1. Installation Linux native

Le binaire RavaLink est autonome : aucun runtime Java, JVM, Gradle ou Lavaplayer n'est requis. Cette procédure installe la release candidate v1.0.0-rc.1. Pour une version ultérieure, remplacez simplement la valeur de VERSION.

Télécharger et installer le binaire

Prérequis : curl, sha256sum, openssl et les outils systemd. Sélectionnez automatiquement l'asset adapté à l'architecture, puis vérifiez son empreinte avant installation :

VERSION="v1.0.0-rc.1"
case "$(uname -m)" in
  x86_64|amd64) ASSET="ravalink-linux-x86_64" ;;
  aarch64|arm64) ASSET="ravalink-linux-aarch64" ;;
  *) echo "Architecture non prise en charge"; exit 1 ;;
esac

BASE="https://github.com/Ravalink-Project/Ravalink/releases/download/$VERSION"
mkdir -p /tmp/ravalink-install
cd /tmp/ravalink-install
curl -fL "$BASE/$ASSET" -o "$ASSET"
curl -fL "$BASE/SHA256SUMS" -o SHA256SUMS
grep "  $ASSET$" SHA256SUMS | sha256sum -c -

sudo install -d -m 0755 /opt/ravalink/bin /etc/ravalink
sudo install -m 0755 "$ASSET" /opt/ravalink/bin/ravalink
sudo curl -fL "https://raw.githubusercontent.com/Ravalink-Project/Ravalink/v1.0.0-rc.1/config/ravalink.example.toml" \
  -o /etc/ravalink/ravalink.toml

Le fichier SHA256SUMS est fourni avec la release et couvre les deux binaires Linux. Ne lancez pas un binaire dont la vérification échoue.

Créer un compte système et un service systemd

Exécutez RavaLink sous un compte dédié, sans privilèges root :

sudo useradd --system --user-group --home-dir /var/lib/ravalink \
  --create-home --shell /usr/sbin/nologin ravalink
sudo chown -R ravalink:ravalink /var/lib/ravalink

sudo sh -c 'printf "RAVALINK_PASSWORD=%s\\n" "$(openssl rand -hex 32)" > /etc/ravalink/ravalink.env'
sudo chmod 600 /etc/ravalink/ravalink.env

Créez /etc/systemd/system/ravalink.service :

[Unit]
Description=RavaLink native audio node
Wants=network-online.target
After=network-online.target

[Service]
Type=simple
User=ravalink
Group=ravalink
WorkingDirectory=/var/lib/ravalink
EnvironmentFile=/etc/ravalink/ravalink.env
Environment=RAVALINK_CONFIG=/etc/ravalink/ravalink.toml
Environment=RAVALINK_ADDRESS=127.0.0.1
Environment=RAVALINK_PORT=2333
Environment=RAVALINK_LOG_LEVEL=info
ExecStart=/opt/ravalink/bin/ravalink
Restart=on-failure
RestartSec=5
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=strict
ProtectHome=true
ReadWritePaths=/var/lib/ravalink

[Install]
WantedBy=multi-user.target

Chargez le service et démarrez-le :

sudo systemctl daemon-reload
sudo systemctl enable --now ravalink
sudo systemctl status ravalink
sudo journalctl -u ravalink -f
Adresse d'écoute : l'exemple systemd écoute sur 127.0.0.1, adapté à un reverse proxy installé sur le même hôte. Si le bot se connecte depuis une autre machine, configurez une adresse joignable (souvent 0.0.0.0) et limitez l'accès avec un pare-feu ou un réseau privé. N'exposez pas le port sans authentification ni contrôle réseau.

Mettre à jour le binaire natif

Conservez votre TOML et votre fichier d'environnement. Téléchargez la nouvelle release, vérifiez SHA256SUMS comme à l'installation, remplacez le binaire, puis redémarrez :

VERSION="v1.0.0-rc.1" # remplacez par la version souhaitée
case "$(uname -m)" in
  x86_64|amd64) ASSET="ravalink-linux-x86_64" ;;
  aarch64|arm64) ASSET="ravalink-linux-aarch64" ;;
  *) echo "Architecture non prise en charge"; exit 1 ;;
esac
BASE="https://github.com/Ravalink-Project/Ravalink/releases/download/$VERSION"
TMP="$(mktemp -d)"
cd "$TMP"
curl -fL "$BASE/$ASSET" -o "$ASSET"
curl -fL "$BASE/SHA256SUMS" -o SHA256SUMS
grep "  $ASSET$" SHA256SUMS | sha256sum -c -

sudo systemctl stop ravalink
sudo install -m 0755 "$TMP/$ASSET" /opt/ravalink/bin/ravalink
sudo systemctl start ravalink
sudo journalctl -u ravalink -n 80 --no-pager
rm -rf "$TMP"

Utilisez l'asset ARM64 sur une machine aarch64. Vérifiez les notes de version et les changements de configuration avant chaque mise à jour.
